# Классификатор обращений

Небольшой учебный проект для автоматической классификации пользовательских обращений.

Скрипт читает сообщения из файла `messages.txt`, определяет категорию каждого обращения и формирует пример чернового ответа на русском языке.

## Задача

Для каждого обращения необходимо определить одну из трёх категорий:

* `справка` — вопросы, связанные с получением справок и документов;
* `жалоба` — сообщения о проблемах, неисправностях или неудовлетворительном качестве обслуживания;
* `другое` — обращения, которые не относятся к первым двум категориям.

После определения категории программа также выводит один пример ответа пользователю.

## Структура проекта

```text
classifier/
├── main.py
├── messages.txt
└── README.md
```

### `main.py`

Основной файл программы.

Он:

1. читает обращения из `messages.txt`;
2. анализирует текст каждого сообщения;
3. определяет категорию;
4. формирует черновик ответа;
5. выводит результат в консоль.

### `messages.txt`

Файл содержит пять тестовых обращений:

```text
Как получить справку о месте учёбы?
В столовой очередь, еда холодная.
Хочу записаться на консультацию завтра.
Пропал Wi-Fi в корпусе B.
Где парковка для гостей?
```

## Как работает классификация

Для решения используется простая классификация по ключевым словам.

Например:

* если в сообщении встречается слово `справка`, обращение относится к категории `справка`;
* слова `пропал`, `холодная`, `очередь`, `не работает`, `проблема` рассматриваются как признаки жалобы;
* если подходящих ключевых слов нет, обращение относится к категории `другое`.

Перед проверкой текст переводится в нижний регистр, поэтому регистр букв не влияет на результат.

Такой подход выбран потому, что в задании используется небольшой фиксированный набор коротких обращений. Для него нет необходимости подключать LLM или внешние API.

## Формирование ответов

После определения категории программа создаёт простой черновик ответа.

Для некоторых обращений предусмотрены более подходящие ответы.

Например, для сообщения о проблемах с Wi-Fi программа предлагает передать информацию технической службе, а для записи на консультацию просит уточнить преподавателя и удобное время.

Ответы являются демонстрационными и при необходимости могут быть заменены на реальные шаблоны организации.

## Требования

Для запуска требуется:

* Python 3;
* дополнительные библиотеки не требуются.

Проект использует только стандартные возможности Python.

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
python main.py
```

Если в системе команда `python` относится к другой версии Python, можно использовать:

```bash
python3 main.py
```

## Пример результата

После запуска программа выводит информацию примерно в следующем виде:

```text
1. Как получить справку о месте учёбы?
Категория: справка
Черновик ответа: Здравствуйте! Для получения справки о месте учёбы обратитесь в деканат или учебный офис вашего факультета.

2. В столовой очередь, еда холодная.
Категория: жалоба
Черновик ответа: Здравствуйте! Спасибо за обратную связь. Мы передадим информацию ответственным сотрудникам.

3. Хочу записаться на консультацию завтра.
Категория: другое
Черновик ответа: Здравствуйте! Для записи на консультацию уточните, пожалуйста, преподавателя и удобное время.

4. Пропал Wi-Fi в корпусе B.
Категория: жалоба
Черновик ответа: Здравствуйте! Спасибо за сообщение. Информацию о проблеме с Wi-Fi передадим технической службе.

5. Где парковка для гостей?
Категория: другое
Черновик ответа: Здравствуйте! Парковка для гостей находится рядом с территорией корпуса. Точное расположение можно уточнить у администрации или охраны.
```

## Почему без LLM

По условию задания категорию можно определять либо правилами, либо с помощью LLM.

В данном решении используются правила, потому что:

* обращений всего пять;
* категории простые;
* не требуется API-ключ;
* нет зависимости от интернета;
* результат классификации предсказуем;
* проект проще запустить и проверить.

Для более крупной системы с большим количеством различных формулировок вместо ключевых слов можно было бы использовать LLM или отдельную модель классификации текста.

## Итог

В результате получен простой классификатор обращений, который:

* читает сообщения из файла;
* относит их к одной из трёх категорий;
* формирует черновик ответа;
* работает локально;
* не требует дополнительных зависимостей и внешних сервисов.
